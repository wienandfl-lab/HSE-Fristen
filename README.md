# Fristenrechner Referendariat (HSE Heidelberg)

Statische Website für M.Ed.-Studierende der Heidelberg School of Education: Wann muss die Masterarbeit angemeldet und abgegeben werden, um im Januar regulär ins Referendariat zu starten?

- **Option 1 – regulär ins Ref:** Ampel (grün/gelb/rot) für Abgabe- und Anmeldedatum
- **Option 2 – als Gasthörer:in ins Ref:** Inhalte folgen

Alles steckt in `index.html` (kein Build nötig). Die Fristen lassen sich oben im Script im `CONFIG`-Block anpassen.

Gehostet über GitHub Pages (Branch `main`, Ordner `/`).
